# IK 真解遗漏修复 patch2：θ1 双分支（`zero-robotic-arm` 固件）

在 patch1（末端位置残差校验剔除伪根）基础上，进一步修复解析逆解**漏掉 θ1 另一个几何根、导致目标可达却返回无解**的问题。可审阅、可复现、已验证。

## 缺陷现象（patch1 之后仍有 62 组"真解被判无解"）

500 组随机 FK→IK 回归（`srand(42)`，限位内采样）：

- patch1（4 候选）：**438/500** 成功，**62 组** `robot_kinematics_inverse` 返回 -1。
- 对这 62 组逐一诊断：它们的臂部构型（θ2/θ3）解析值与真解完全一致，**唯一差别在 θ1**：
  - 62 个点的正确 θ1 全部是固件给出 θ1 的**另一个符号根**（半角法 `tan(θ/2)` 中 `u=+√` 与 `u=−√` 的另一支）；
  - 固件原逻辑用 `if (fabs(py - eq2) > ERR) u = -u;` 做一次性二选一，该判据在边界情况下选错符号，且只保留一个根，错选即漏解。

## 修复原理（只动 θ1 选根，其余公式不变）

不再依赖 `py` 判据在两支里二选一，而是**对每个 (θ2,θ3) 臂部构型显式枚举 θ1 的两个几何根**：

- θ1 正根：`u = +√((−px+eq1)/(px+eq1))`，`θ1 = 2·atan(u)`；
- θ1 负根：`θ1 = −2·atan(u)`；
- 两个根各自重算腕部 θ5/θ4/θ6。

候选解数量由 4 增至 8，索引布局：

```
index = θ3idx*4 + θ2idx*2 + θ1idx      （θ3/θ2/θ1 各两支，共 2³ = 8）
```

最后统一由 patch1 的流程裁决：**末端位置残差校验（>1mm 判伪根）→ 关节限位 → 按当前关节角加权距离选最优**。枚举了全部几何根后，位置校验能稳定地选出唯一正确的那一支，不再依赖单点二选一。

> 不需要 `θ1 ± π` 分支：诊断显示 62 个失败点全部由 `−θ1`（半角另一符号）覆盖，`θ1+π`、`−θ1+π` 贡献为 0。

## 验证结果（500 组）

```
patch2（θ1 双分支）robot_kinematics_inverse（500 组）
位置误差<1mm 占 100.0%，最大 0.0119 mm，平均 0.00021 mm，无解 0
对照：patch1（4 候选）438/500 成功、62 无解；patch2（8 候选）为 500/500。
```

即解析逆解成功率由 87.6%（438/500）提升到 **100%（500/500）**，且 patch1 原本能解的 438 组不退化。

> 本补丁采用最小侵入方式：仅修改 `robot_kinematics.h` 的 `RESULT_NUM` 与 `robot_kinematics.c` 的 `calc_theta2` / `calc_theta1` 三处，其余函数与注释保持原样；`ik_theta1_dualbranch.patch` 为相对 patch1 的完整统一 diff（约 100 行）。

## 与 numeric_ik 的关系（双保险）

- **patch2（本目录）**：解析层修复，确定性、零迭代、计算量小，是首选方案。500 组采样已全覆盖。
- **`../numeric_ik/`**：阻尼最小二乘（DLS）数值逆解，作为与解析法独立的**第二保险**。当出现解析几何未覆盖的奇异/边界目标时，可在 8 个解析候选全部无效后调用它兜底；数值兜底在同一批 62 个失败点上也已验证 62/62 成功（位置最大 0.988mm、姿态最大 0.108°）。

两条路线相互独立、任一条都可单独达成 100%，建议固件默认走 patch2 解析、numeric_ik 作为可选兜底。
