# 数值逆运动学兜底（DLS 阻尼最小二乘）

与固件解析逆解完全独立的 **6 自由度数值 IK**，作为解析法的第二保险/兜底。可审阅、可复现、已验证。

## 用途

- 当解析逆解（patch1/patch2）在奇异点、边界构型或几何未覆盖目标上返回“无解”时，用数值迭代兜底；
- 也可作为不依赖具体解析推导的通用 6R 逆解参考实现。

## 算法

- **正运动学**：与固件完全一致的 MDH 参数（`A=Rx(α)·Rz(θ)·Tz(d)·Tx(a)`，见 `numeric_ik.h` 的 `NUM_IK_DH`）。
- **迭代**：阻尼最小二乘（DLS），`q ← q + Jᵀ(JJᵀ + λ²I)⁻¹ e`
  - 数值雅可比（中心差分）；
  - 误差含位置（米）与姿态（世界系三轴方向 `0.5·Σ r_cur × r_tgt`）；
  - 关节限位弧度钳制（J2~J5 有限位；J1/J6 整周自由，输出再映射回 0..360°）；
  - 单步关节增量限幅、最大迭代次数与收敛阈值见 `numeric_ik.h`。
- **多起点**：用目标附近的若干种子（含解析候选）迭代，取收敛且残差最小者。

> 关键符号：误差定义为 `e = x_target − x_forward(q)`，其差分为 `−J`，因此数值雅可比必须取负 `J[:,i] = −(e(q+δ)−e(q−δ))/(2δ)`，否则 DLS 反向发散。该问题在排查中已定位并修正。

## 文件说明

| 文件 | 说明 |
|---|---|
| `numeric_ik.h` | 接口、MDH 参数表、限位与 DLS 调参常量 |
| `numeric_ik.c` | FK、数值雅可比、DLS 6×6 高斯消元、多起点求解 |
| `verify_numeric_ik.c` | 500 组验证：真解种子自检 + 解析失败点兜底 |
| `Makefile` | x86 构建：`make && ./verify_numeric_ik` |

## 与 patch2 的关系

- `../patch2/`（θ1 双分支）是解析层的确定性修复，计算量小、首选；
- 本目录是与之独立的数值兜底，可在解析 8 候选全部无效时启用。两者在同一批 62 个失败点上均独立达到 100%。
